# Master Context

## Project Identity
- **Name:** AI-Chess
- **Repository:** https://github.com/Bekimoon0043/AI-Chess
- **License:** MIT
- **Author:** Bekimoon0043

## Vision
Build a production-ready, fully client-side AI Chess Web Application hosted free on GitHub Pages. All logic (engine, state, audio, rendering) runs in the browser with offline PWA support.

## Current State
- **Version:** 0.1.0
- **Status:** MVP Functional — core gameplay complete, AI operational, PWA baseline working
- **Architecture:** Vanilla HTML/CSS/JS (switched from planned React/Vite for simplicity)

## Goals
1. Provide an accessible, offline-capable chess experience
2. Demonstrate clean vanilla JS architecture for browser-based games
3. Maintain structured AI memory for continuous development

## Non-Goals
- Online multiplayer (requires backend)
- Cloud save / user accounts
- Tournament management
- Server-side processing

## Key Metrics
- Zero hosting cost
- < 100KB total JS payload
- < 3s Time to Interactive on 3G
- Lighthouse Performance > 90
